# 版本路线

每一版只引入一个主要工程概念，以便把 GitHub 历史、Verilog 代码和设计指标对应起来。

## V1：组合逻辑基线

- 64 次条件移位相加，无时钟。
- 目标是正确性和可读性。
- 预期问题：组合路径很长、资源可能较大。
- 验证重点：128 位结果、边界值、随机向量。

## V2：流水线乘法器

- 增加时钟、输入寄存器和输出寄存器。
- 或先用运算符 `a * b` 让 Vivado 推断 DSP，再分析实现差异。
- 学习目标：时延（latency）、吞吐率（throughput）和时序路径。
- GitHub 目标：首次完成分支、Pull Request、合并和标签。

## V3：逐位迭代乘法器

- 每周期处理一位，若干周期后输出。
- 学习目标：用时间换面积，理解状态机和握手信号。
- GitHub 目标：提交对比数据和设计决策。

## V4：可选优化

- Radix-4 Booth 编码。
- 有符号乘法和饱和/溢出处理。
- 综合、实现和时序报告。
- 学习目标：功能正确不等于工程指标合格，所有优化都要用数据证明。

版本号名称可以在每版开始前调整；每个版本完成后都要更新 README 中的“当前版本”，并记录测试和综合结果。
