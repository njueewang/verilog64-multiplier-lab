# V1 验证与资源基线

测试环境：

- Vivado 2025.2
- 目标器件：Artix-7 `xc7a35tcsg324-1`
- 日期：2026-10-30

## 功能仿真

测试平台覆盖：

- `0 × 0`
- `1 × 1`
- `1 × (2^64 - 1)`
- `(2^64 - 1) × (2^64 - 1)`
- 两个 64 位大数相乘
- 最高位为 1 的值
- 两个 32 位有效范围内的大数相乘
- 200 组随机 64 位输入

结果：

```text
MULTIPLIER64 V1 TEST PASSED: 208 vectors
```

这 208 组输入都通过。测试平台在第 208 ns 结束，所有输出都等于独立计算的 128 位期望值。

## 综合结果

```text
Synthesis finished with 0 errors, 0 critical warnings and 0 warnings.
```

| 资源 | V1 使用量 | 器件可用量 | 占比 |

| Slice LUT | 4,276 | 20,800 | 20.56% |
| Slice Register | 0 | 41,600 | 0.00% |
| DSP | 0 | 90 | 0.00% |
| Block RAM | 0 | 50 | 0.00% |

这里的寄存器为 0，是因为 V1 是组合逻辑；LUT 较高，是因为 64 次条件移位相加形成了较长的组合加法/选择路径。报告中的 I/O 占比超过 100%，只说明这个没有引脚约束的教学顶层同时暴露了 256 个端口；能否上板要结合具体封装和使用的接口判断，不能按全部端口同时占用 I/O 来理解。

V1 尚未添加时钟约束，因此时序报告的 WNS 为 `NA`。V2 增加时钟后，才能比较真实的工作频率和流水线收益。
